使い方

  • 選択/移動: ノードをドラッグ→接続エッジ自動追従
  • ノード追加: 空きをクリック / エッジ: A→Bを順にクリック
  • 入口: kind=entrance にし、パネルで「対応入口を作成」→ 全体マップ側を自動生成
  • 階段: kind=stairs にし、「隣接フロアに作成」→ 上下階に同IDを生成
  • QR候補: Routeノードをクリック。既存候補は一覧または黄色マーカーで選択
  • Undo / Redo: Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z（WindowsはCtrl+Yも可）
  • ホイールでズーム / 空きドラッグでパン / VNEQD Del

出力後: DLした各SVGを public/maps/ に上書き → bun run generate:routes → bun run verify:routes
