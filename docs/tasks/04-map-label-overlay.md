# 04: 地図ラベルのReact再描画

## GOAL

地図SVGに焼き込まれた `<text>`(Meiryo UI指定・非Windows環境で明朝体フォールバック・ズームで比例拡大)を表示から外し、React側のラベルレイヤーでNoto Sans JP・画面固定サイズで再描画する。ズームしてもラベルが巨大化せず、ズームアウト時は重要ラベルのみに間引かれる状態にする。

## 参照

- [SPEC.md](../SPEC.md) §3.1.1「マップ内ビジュアル仕様」(このブリーフの正)
- `src/features/map/MapCanvas.tsx`(SVGロード・viewBoxズーム・マーカーの逆スケール実装が既にある)
- `public/maps/*.svg`(資産は**変更禁止**。読み取りのみ)

## やること

1. SVGロード時に `<text>`(`tspan` 含む)から文言・アンカー位置・元font-sizeを抽出し、元テキストを非表示化する
2. route層とmarker層の間に専用ラベルレイヤーを設け、抽出したラベルをNoto Sans JPで描画する
3. ラベルの画面上サイズを固定する(マーカーと同じ逆スケール方式。目標11〜13px)
4. 元font-sizeを重要度としたズーム連動の間引きを実装する(ズームアウト時は大物件のみ)
5. 複数行ラベル(tspan複数)は1ラベルとして行間を再構成する
6. LHシートの `fill_1F`/`fill_2F` のような表示切替グループ内のラベルは、元グループの表示状態に追従させる(非表示フロアのラベルを出さない)
