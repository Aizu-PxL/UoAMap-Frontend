# 03j: ルート最終検証と引き継ぎ整備

## GOAL

03d〜03iで実装した残りのルート全体を横断検証し、次のセッションが再調査せず別機能へ着手できる引き継ぎ資料を残して、ステップ3をクリーンなコミット状態で完了する。

## やること

1. 03d〜03iの変更を仕様・作図契約・既存SVG保護ルールに照らしてレビューする
2. 全自動検証と代表的な屋内・建物横断・複数階ルートを再確認する
3. 実装結果、再開手順、設計判断、既知の要確認事項を `docs/HANDOFF.md` に集約する
4. STATUSとWORKFLOWから引き継ぎ資料へ到達できるようにする
