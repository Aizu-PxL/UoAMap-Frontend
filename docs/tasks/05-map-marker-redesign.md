# 05: マーカー刷新とズーム連動表示制御

## GOAL

マーカー・ピンの色をCSSトークン化し、イベントバッジを軽量な円形デザインへ刷新する。キャンパス全体シートではイベントを建物単位に集約した件数付きバッジで表示し、建物シートで個別バッジを出す。黒い矩形バッジ(1.6xスケール)と重なり問題を解消する。

## 参照

- [SPEC.md](../SPEC.md) §3.1.1「マップ内ビジュアル仕様」(このブリーフの正)
- `src/features/map/MapCanvas.tsx`(既存マーカー描画: PIN_PATH / EVENT_MARKER_*)
- `src/styles/global.css`(既存 `--map-marker-*` 変数)
- `src/data/`(Place・Event・建物の関係の解決に使う)

## やること

1. マーカー色トークンを整理する: `--map-marker-destination`(#e0524d系)/ `--map-marker-current`(#1769aa系維持)/ `--map-marker-focus`(`--color-accent`)。描画側のハードコード色を全てトークン参照へ置換する
2. イベントバッジを円形(白地+teal縁+人型グリフ、画面上直径22〜26px)へ刷新し、旧EVENT_MARKER(黒矩形・1.6x)を廃止する
3. キャンパス全体シート: 建物シート内のイベントは建物アンカーに集約バッジ(件数表示付き)を描画し、タップで建物シートへ切り替える。キャンパス専用地点のイベントは場所単位の件数付きバッジを描画し、タップで `/events?highlight=` へ遷移する
4. 建物シート: 従来どおり地点ごとの個別バッジ。タップで `/events?highlight=` へ(既存挙動維持)
5. 既存ルール維持: 同一地点複数イベントの集約、現在地・目的地・注目ピンと同一地点ではイベントバッジ省略

## SCOPE

### 建物集約の解決方法

イベントの `placeId` から `Place.floorId`、`Floor.sheetId` の順に解決し、建物シートIDをキャンパスSVGの `building_*` アンカーへ対応付ける。キャンパス上の建物Place(UBIC等)は自身の `svgElementId` を使う。建物シートへ解決できない `floorId="campus"` の地点(講堂、ロボット格納庫等)は場所単位の件数付きバッジとして別に描画し、先頭イベントの `/events?highlight=` へ遷移する。
