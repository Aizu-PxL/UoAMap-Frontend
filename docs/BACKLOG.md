## UI修正(2026-07-19 ユーザーフィードバック)

### 1. イベント開催地マーカー

Figma Screen/01 の `Marker/Arrow`(現名)の正体。**イベントが行われている地点に立つマーカー**。

- 挙動: 地図上のイベント開催地にマーカー表示 → タップすると検索(イベント一覧)タブが開き、該当イベントカードが**強調表示**される
- 実装方針案: Event→placeId→位置は既存データで解決可能。強調はURL案 `/events?highlight=:eventId`(URLが正の原則に沿う)
- 先行タスク: SPEC §3.1(地図表示)・§3.4(イベント検索)への仕様追記。Figmaの `Marker/Arrow` を `Marker/Event` 等へ改名
- 受入条件案: 開催中イベントのある地点にマーカーが出る / タップで検索タブ+該当カードが視覚的に強調され、スクロールで見える位置に来る

### 2. クリック可能な建物のアフォーダンス

全体マップで「開ける」建物(研究棟・学生ホール・講義棟・UBIC・LICTiA の5つ)に**薄い枠線**を表示し、タップできることを視覚的に伝える。

- 実装箇所: MapCanvasが building_* に role/tabindex を付けている箇所でスタイルも付与(CSS or SVG stroke直接)
- Figma側にも同じ表現を追加して正を揃える
- 受入条件案: キャンパス全体図で5建物に枠線が見える / 開けない建物には出ない

### 3. フロア切替時の座標維持

ズーム中に同一建物の別フロアへ切り替えても、**同じ座標・同じズームのまま**表示する(現在は切替のたびに全体表示へリセット)。

- LH(1シート内切替)は自明に可能
- **要調査**: RQ1F/2F/3F・SH1F/2Fは別SVGファイル。各フロアの座標系(viewBoxと建物の描画位置)が揃っているかを先に確認する。揃っていなければフロア間オフセット補正表が必要
- 受入条件案: 建物内でズームした状態でフロアボタンを押すと、同じ場所がズームされたまま別フロアに切り替わる。キャンパス⇄建物の切替は従来通りリセットで良い

### 4. 目的地設定〜ナビ開始フローの再検討(未確定)

「地図」パネル(`/` のときシートに出る現在地/目的地ステータス画面)はFigmaに存在せず、あまり良くない。フロー全体を再検討予定で、**変更になる可能性が高い**。

- 現状の事実: このパネルは `src/features/map/MapPanel.tsx` 単体で、地図・フォーカス・マーカーのロジックは背面(MapCanvas/AppLayout/URL)にある。**パネルの差し替え・削除は地図機能に影響しない**
- Figma Screen/01 の挙動(シート最小化で地図を見せる)への変更も、パネル1ファイル+シート初期高さの変更で済む
- ユーザーがフローを決めたら: SPEC §3.2/§2 を更新 → Figmaに画面を起こす → ブリーフ化
