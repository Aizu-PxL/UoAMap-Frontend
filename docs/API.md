# UoAMap API契約(ドラフト v0)

最終更新: 2026-07-31(正式Event IDと内部keyを分離)

フロントエンドが期待するバックエンドAPIの契約。バックエンドはこれに合わせて実装する。
変更はフロント・バックエンド双方合意の上でこのファイルを先に更新する。

方針(SPEC.md 4章・5章より):
- バックエンドの役割は**イベント・場所対応・QR対応表の管理と配信**のみ
- 経路計算・検索はフロント側で行うため、**経路APIと検索APIは存在しない**
- レスポンスはすべてJSON・UTF-8。認証なし(公開読み取り専用API)
- 書き込み系(登録・編集)は管理用であり、この契約の対象外(バックエンド内部の自由。スプレッドシート取込等でも良い)

## エンドポイント

### GET /api/events

イベント全件を返す。フロントは起動時に1回取得し、以後クライアント側で検索・絞り込みする。

```jsonc
{
  "events": [
    {
      "key": "L1",                         // フロント内部の一意キー
      "id": "L1",                          // 公式タイムテーブルの記号
      "title": "入試説明会",
      "description": "……",
      "placeId": "lh_room_lth_1",          // フロントのPlace ID(SVG由来レジストリと一致必須)
      "tags": ["L"],
      "timeSlots": [
        { "start": "2026-08-08T10:20:00+09:00", "end": "2026-08-08T10:50:00+09:00" }
      ]
    }
  ]
}
```

`timeSlots[].end`は、公式情報に終了時刻がない場合だけ省略できる。フロントはその場合、開始時刻のみを「9:40〜」の形式で表示し、推測した終了時刻を補完しない。

`key`は全Eventで必須かつ年度内一意。正式IDがあるEventは`key === id`とする。総合案内・自由見学・休憩所・ランチ営業・売店営業は`id`を省略し、`service-*`形式の内部keyだけを返す。`id`に使用できる先頭文字は`A/L/E/U/P/T/M/G/R`だけで、タグIDは同じ先頭文字に一致させる。正式IDがないEventの`tags`は空配列とする。

### GET /api/tags

タグ(検索フィルタのチップ)一覧。表示順で返す。

```jsonc
{
  "tags": [
    { "id": "A", "label": "大学説明会" },
    { "id": "L", "label": "入試説明会" },
    { "id": "E", "label": "早期（飛び）入試説明会" },
    { "id": "U", "label": "保護者向け説明会" },
    { "id": "P", "label": "研究室公開" },
    { "id": "T", "label": "キャンパスツアー" },
    { "id": "M", "label": "体験授業" },
    { "id": "G", "label": "なんでも相談会" },
    { "id": "R", "label": "受験勉強相談" }
  ]
}
```

### GET /api/qrs/{qrId}

QR IDを地点に解決する。QRの貼り替え・再割当はこの表の更新だけで完結する。

```jsonc
// 200
{ "qrId": "Q001", "placeId": "main_node_11" }

// 404: 未知のqrId → フロントはエラー表示(地図はデフォルト表示)
{ "error": "QR_NOT_FOUND", "qrId": "Q999" }
```

種別(固定/可変)や設置場所メモはバックエンド内部の管理項目であり、レスポンスには含めない。

## 共通事項

- `placeId` の語彙はフロントのPlaceレジストリ(SVGから生成)が正。バックエンドに登録する際はフロントが書き出す一覧(将来 `places.json` として提供)から選ぶ
- イベントデータは年度ごとに総入れ替え。IDは年度内でユニークであれば良い
- キャッシュ: `/api/events`・`/api/tags` は数分程度のキャッシュ可。`/api/qrs/{qrId}` は当日貼り替え運用があるためキャッシュ短め(60s以下)を推奨
- CORS: 本番フロントのオリジンを許可(ホスティング先確定後に記載)。可能なら同一originの `/api` とし、確定値は [PRODUCTION.md](PRODUCTION.md) §3にも記録する
